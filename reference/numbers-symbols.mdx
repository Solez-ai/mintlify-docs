All numbers, punctuation marks, and mathematical operators in BrailleBridge live in the **Shift layer** — you access them by holding the physical Shift key while pressing a dot chord. There is no separate number mode to enter or exit, and no numeric indicator cell to type before digits. Press Shift, press the chord, release — the character is sent immediately. This works identically in both English and Bangla modes, so you can type a complete arithmetic expression without switching languages.

## Numbers 0–9

Numbers map directly onto the first-decade letter chords (A through J). Shift + A produces `1`, Shift + B produces `2`, and so on through Shift + I for `9`. Shift + J produces `0`, completing the ten digits.

| Shift + Letter | Number | Dots |
|---|---|---|
| A | 1 | 1 |
| B | 2 | 1, 2 |
| C | 3 | 1, 4 |
| D | 4 | 1, 4, 5 |
| E | 5 | 1, 5 |
| F | 6 | 1, 2, 4 |
| G | 7 | 1, 2, 4, 5 |
| H | 8 | 1, 2, 5 |
| I | 9 | 2, 4 |
| J | 0 | 2, 4, 5 |

## Punctuation

The four core punctuation marks each have their own Shift chord. Because these chords do not overlap with any first-decade letter, you can type them freely without accidentally triggering a digit.

| Symbol | Name | Dots |
|---|---|---|
| `,` | Comma | 2 |
| `;` | Semicolon | 2, 3 |
| `:` | Colon | 2, 5 |
| `.` | Period / decimal point | 2, 5, 6 |

## Mathematical operators

The five standard arithmetic operators each have a dedicated Shift chord. The chord values are drawn from the international Braille mathematics standard and are the same regardless of whether the device is in English or Bangla mode.

| Symbol | Name | Bangla name | Dots |
|---|---|---|---|
| `+` | Plus | যোগ | 2, 3, 5 |
| `−` | Minus | বিয়োগ | 3, 6 |
| `×` | Multiplication | গুণ | 2, 3, 6 |
| `÷` | Division | ভাগ | 3, 4 |
| `=` | Equals | সমান | 2, 3, 5, 6 |

## Typing a math expression

The steps below show exactly how to type `3 + 4 = 7` from left to right. Hold Shift for each step except the Space presses.

1. **Shift + C** → `3` (dots 1, 4)
2. **Space** → ` ` (space)
3. **Shift + dots 2, 3, 5** → `+` (plus)
4. **Space** → ` ` (space)
5. **Shift + D** → `4` (dots 1, 4, 5)
6. **Space** → ` ` (space)
7. **Shift + dots 2, 3, 5, 6** → `=` (equals)
8. **Space** → ` ` (space)
9. **Shift + G** → `7` (dots 1, 2, 4, 5)

The teacher console receives each character as it is sent and displays the complete expression `3 + 4 = 7` in real time.

<Tip>
Numbers and operators both live in the Shift layer, so you can type a complete arithmetic expression without leaving Shift mode. Hold Shift, press your digit or operator chords one at a time, and release Shift only when you want to go back to letter input. Spaces are pressed without Shift since they have their own dedicated key.
</Tip>

<Note>
The period (dots 2, 5, 6) doubles as a **decimal point** in mathematical work. To type `3.14`, enter Shift + C → Shift + period chord → Shift + A → Shift + D — all within the Shift layer.
</Note>
