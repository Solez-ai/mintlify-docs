BrailleBridge removes the sighted human scribe from blind students' classrooms and examinations. Instead of dictating answers aloud to a writer, a student types silently on a compact mechanical six-dot Braille keyboard, receives audio confirmation through their own screen reader, and streams clean English or Bangla text straight to the teacher's console over Bluetooth or USB.

## How Does the Current Production Architecture Compare to the Legacy Prototype?

BrailleBridge evolved from a single-student USB breadboard prototype into a Bluetooth-first, multi-student classroom platform built on the **BB1 Wiring Board v4** PCB (`66.0 × 52.0 × 1.2 mm`) with a plug-in 5 V buck-boost power module (`J5`) and selector jumper (`JP1`). Unlike the legacy fixed-window prototype, the production system uses a decode-on-release chording state machine and a multi-threaded Python (`PyQt6` + `Bleak` + `PySerial`) and Android (`Kotlin` + `Jetpack Compose`) relay capable of streaming multiple physical ESP32 units simultaneously.

| Subsystem | Legacy Prototype | Current Production Architecture |
|---|---|---|
| **Primary Transport** | USB Serial (`115200` baud) + single-device BLE HID | **Bluetooth-first**: BLE HID Keyboard + concurrent **BLE Nordic UART Service (NUS)** + WinRT auto-radio activation + hybrid USB failover |
| **Multi-Device Scale** | 1 student per browser tab (Web Serial) | **Hardware-verified multi-ESP32 pool** (`BrailleBridge 2` & `BrailleBridge 3` tested simultaneously) in PyQt6 Desktop (`RelayManager` + `BleManager`) and Android (`BleProxyService`) |
| **Hardware Wiring** | Loose breadboard / perfboard wires, USB-only | **BB1 Wiring Board v4** — custom 2-layer KiCad 10 PCB (`66 × 52 × 1.2 mm`), socketed `5 V` buck-boost regulator (`J5`, `3–16 V`) + `JP1` bypass/regulated selector + dual `1N5819` diodes (`D1`, `D2`) + `38-pin` ESP32 sockets |
| **Chording Engine** | Fixed `180 ms` commit window | **Decode-on-release** state machine (`DEBOUNCE_MS = 15`, live-tunable `5–50 ms`, `CHORD_HOLD_MAX_MS = 5000`) + Shift tap-for-backspace + Dot 6 Capital lock |
| **Teacher Software** | Static HTML Web Serial prototype | **Native PyQt6 Microsoft Word–Style Desktop Suite** (permanent 22 pt Zoom canvas, per-student Teacher document tabs, 100%–300% Sound Booster) + **Android Jetpack Compose App** |
| **Web Platform** | Basic demo page | Virtual 6-dot pad, Web Bluetooth + Web Serial bridge, **Three.js `.glb` 3D PCB viewer (`bb1_wiring_board_v4.glb`)**, and **2D KiCad SVG layer inspector** |

## Who Uses BrailleBridge in Classrooms and Examinations?

BrailleBridge serves four primary groups: blind and visually impaired students who write independently in English or Bangla Braille, sighted teachers and exam invigilators who read real-time translated transcripts without knowing Braille, schools and makerspaces that assemble units locally for under $15 USD using regional battery supplies, and developers integrating with the open BLE NUS / USB Serial protocol.
