BrailleBridge removes the sighted human scribe from blind students' classrooms and examinations. Instead of dictating answers aloud to a writer, a student types silently on a compact mechanical six-dot Braille keyboard, receives audio confirmation through their own screen reader, and streams clean English or Bangla text straight to the teacher's console over Bluetooth or USB.

## What Changed in the Current Generation

BrailleBridge evolved from a single breadboard/perfboard USB prototype into a complete multi-device hardware and software platform:

| Subsystem | Legacy Prototype | Current Production Architecture |
|---|---|---|
| **Primary Transport** | USB Serial (`115200` baud) + single-device BLE HID | **Bluetooth-first**: BLE HID Keyboard + concurrent **BLE Nordic UART Service (NUS)** + USB Serial fallback |
| **Multi-Device Scale** | 1 student per browser tab (Web Serial) | **Multi-bridge pool** in both PyQt6 Desktop (`RelayManager` + `BleManager`) and Android (`BleProxyService` `ConcurrentHashMap`) |
| **Hardware Wiring** | Loose breadboard / perfboard wires, USB-only | **BB1 Wiring Board v2** — custom 2-layer KiCad 10 PCB (`66 × 41 × 1.2 mm`), `4×AA` battery power via slide switch & `1N5819`, `38-pin` ESP32 female sockets |
| **Chording Engine** | Fixed `180 ms` commit window | **Decode-on-release** state machine (`DEBOUNCE_MS = 15`, `CHORD_HOLD_MAX_MS = 5000`) + Shift tap-for-backspace + Dot 6 Capital lock |
| **Teacher Software** | Static HTML Web Serial prototype | **Native PyQt6 Desktop Suite** + **Android Jetpack Compose App** with Smart Formatter, Google Translate, TTS, and persistent rosters |
| **Web Platform** | Basic demo page | Virtual 6-dot pad, Web Bluetooth + Web Serial bridge, **Three.js `.glb` 3D PCB viewer**, and **2D KiCad SVG layer inspector** |
