The BrailleBridge Desktop App (`braille-desktop/`) is a native **PyQt6** editorial document suite (`BrailleBridgeWindow`) engineered for school classrooms, individual learners, and exam invigilators. Styled after Microsoft Word with official **Midnight Navy (`#001242`)**, **Warm Paper Cream (`#FAF6F0`)**, and **Bridge Orange (`#FF7315`)** branding in a clean Light-mode workspace, it supports simultaneous multi-ESP32 Bluetooth & USB Serial connections, a 100%–300% WAV audio sound booster, and persistent local export archives.

<Check>
  **Tested & Verified with Multiple ESP32 Units:** The desktop suite has been hardware-tested with multiple physical ESP32 devices (**`BrailleBridge 2`** and **`BrailleBridge 3`**) connected simultaneously, successfully streaming live student writing into separate per-student Word document tabs in real time.
</Check>

## Installation & Dependencies

From `braille-desktop/requirements.txt`:

```text
PyQt6>=6.6.0
bleak>=0.22.0
pyserial>=3.5
pyttsx3>=2.90
```

```bash
cd braille-desktop
pip install -r requirements.txt
python main.py
```

## Architecture & Core Modules

| File | Responsibility |
|---|---|
| `main.py` | `BrailleBridgeWindow(QMainWindow)` with 4 Microsoft Word–style views (`student`, `teacher`, `logs`, `learn`), permanent 22 pt Zoom paper canvas, per-student Teacher Document Tab Bar, full-width Exports ribbon, `BrailleDotButton`, `MiniBrailleCell`, `StatusDot`, and `ThemePalette.LIGHT` (Midnight Navy `#001242`, Warm Cream `#FAF6F0`, Bridge Orange `#FF7315`) |
| `relay.py` | `RelayManager` (concurrent multi-ESP32 BLE + USB Serial pool), `BleManager` (`bleak` + Windows `winrt.windows.devices.radios` auto-radio activation + serialized `_op_lock` + hybrid USB-powered failover), `RelayBridge` (`QObject` thread-safe Qt signals), ROM `BOOT_PREFIXES` & inline `SYSTEM:*` stream sanitizer, JSON & `.log` persistence |
| `protocol.py` | Complete English & Bangla Braille dictionary parity, `SmartFormatter`, `decode_text_to_steps`, `translate_text` (Google Translate), and `SpeechEngine` (with 100%–300% 16-bit PCM WAV Sound Booster) |
| `icons.py` | Crisp Lucide-style SVG icon renderer for the Light-mode editorial workspace |

## Universal Cross-Platform Data Directory

`get_app_data_dir()` in `relay.py` stores classroom data per user so the app works identically on any PC (overridable via `BRAILLEBRIDGE_DATA_DIR`):

- **Windows**: `%LOCALAPPDATA%\BrailleBridge`
- **macOS**: `~/Library/Application Support/BrailleBridge`
- **Linux**: `~/.local/share/BrailleBridge`

Persisted files: `roster.json` (last 2,000 chars per student), `assignments.json`, `student_logs.json` (capped at 200 entries), `settings.json`, plus timestamped `.log` transcripts in `logs/`.
