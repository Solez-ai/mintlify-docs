The BrailleBridge Desktop App (`braille-desktop/`) is a native **PyQt6** application (`BrailleBridgeWindow`) engineered for school classrooms, individual learners, and exam invigilators. It replaces the legacy browser-only Web Serial prototype with persistent local storage, simultaneous multi-device Bluetooth & USB Serial connections, SVG vector icons (`icons.py`), and Light/Dark themes.

## Installation & Dependencies

From `braille-desktop/requirements.txt`:

```text
PyQt6>=6.6.0
bleak>=0.22.0
pyserial>=3.5
pyttsx3>=2.90
```

```bash
cd braille-desktop
pip install -r requirements.txt
python main.py
```

## Architecture & Core Modules

| File | Responsibility |
|---|---|
| `main.py` | `BrailleBridgeWindow(QMainWindow)` with 4 stacked views (`student`, `teacher`, `logs`, `learn`), `BrailleDotButton`, `MiniBrailleCell`, `StatusDot`, and `ThemePalette.DARK` / `LIGHT` |
| `relay.py` | `RelayManager` (concurrent BLE + USB Serial pool), `BleManager` (`bleak` + Windows `winrt`), `RelayBridge` (`QObject` thread-safe Qt signals), ROM `BOOT_PREFIXES` filter, JSON & `.log` persistence |
| `protocol.py` | Complete English & Bangla Braille dictionary parity, `SmartFormatter`, `decode_text_to_steps`, `translate_text` (Google Translate), and `SpeechEngine` |
| `icons.py` | Crisp Lucide-style SVG icon renderer for Light and Dark modes |

## Universal Cross-Platform Data Directory

`get_app_data_dir()` in `relay.py` stores classroom data per user so the app works identically on any PC (overridable via `BRAILLEBRIDGE_DATA_DIR`):

- **Windows**: `%LOCALAPPDATA%\BrailleBridge`
- **macOS**: `~/Library/Application Support/BrailleBridge`
- **Linux**: `~/.local/share/BrailleBridge`

Persisted files: `roster.json` (last 2,000 chars per student), `assignments.json`, `student_logs.json` (capped at 200 entries), `settings.json`, plus timestamped `.log` transcripts in `logs/`.
