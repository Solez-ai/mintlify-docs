BrailleBridge uses a custom `BBKeyboard` stack (`braile/BBKeyboard.h` and `braile/BBKeyboard.cpp`, built on `ESP32_BLE_Keyboard` + ESP32 Arduino BLE) that exposes **two concurrent BLE services** alongside **USB Serial (`115200` baud)**.

## Connection & GATT Parameters

| Parameter | Value |
|---|---|
| **BLE Advertised Name** | `BrailleBridge` (or `BrailleBridge 2`, `BrailleBridge 3` for multi-ESP32 classroom units; max 15 chars) |
| **BLE MTU** | `247` bytes (`BLEDevice::setMTU(247)`) |
| **BLE Security** | `ESP_LE_AUTH_REQ_SC_MITM_BOND` |
| **HID PnP ID** | `vid = 0x05ac`, `pid = 0x820a`, `version = 0x0210` |
| **NUS Service UUID** | `6E400001-B5A3-F393-E0A9-E50E24DCCA9E` |
| **NUS TX UUID (ESP32 → Host)** | `6E400002-B5A3-F393-E0A9-E50E24DCCA9E` (`PROPERTY_NOTIFY` + `BLE2902` CCCD) |
| **NUS RX UUID (Host → ESP32)** | `6E400003-B5A3-F393-E0A9-E50E24DCCA9E` (`PROPERTY_WRITE \| PROPERTY_WRITE_NR`) |
| **USB Serial** | `115200` baud, 8N1, UTF-8 |

## Concurrency & Thread-Safe BLE Event Queue

BLE callbacks run on the NimBLE/Bluedroid task, while chord scanning runs in Arduino `loop()`. `BBKeyboard.cpp` queues `NUS_EVT_CONNECT` (`1`), `NUS_EVT_DISCONNECT` (`2`), and `NUS_EVT_RX` (`3`) events into a `portMUX_TYPE`-guarded ring buffer (`_nusEvents[8]`) and drains them safely in `loop()` via `bleKeyboard.processEvents()`.

`streamText()` appends `'\n'` inside the same BLE notification chunk as the payload (split up to `mtu - 3` bytes) so desktop and Android clients never receive split newline frames.

## Protocol Messages

### Outgoing (`Device → Host` via BLE NUS & USB Serial)

| Message | Meaning |
|---|---|
| `SYSTEM: BrailleBridge Connected. Waiting for BLE...` | Printed on USB Serial at boot |
| `LANG:en` | Active language switched to English |
| `LANG:bn` | Active language switched to Bangla |
| `SYSTEM:CAP_ONCE` | Dot 6 Capital Sign active for next character |
| `SYSTEM:CAP_LOCK` | Dot 6 Capital Lock active |
| `SYSTEM:CAP_OFF` | Capital state cleared |
| `SYSTEM:BKSP` | Shift-tap Backspace triggered (also sends BLE HID `0xB2`) |
| `Invalid` | Unrecognized command received on NUS RX |
| `<utf8_char>` | Translated English or Bangla character |

### Incoming (`Host → Device` via BLE NUS RX `6E400003-...`)

| Command | Effect |
|---|---|
| `SYSTEM:START` / `RESET` | Sent automatically on Teacher BLE/USB connect (and on Clear) to synchronize or restart classroom demo streaming |
| `LANG:en` | Switches firmware to English and echoes `LANG:en` |
| `LANG:bn` | Switches firmware to Bangla and echoes `LANG:bn` |
| `DEBOUNCE:<5..50>` | Live-updates switch debounce filter (`ms`) and echoes `SYSTEM:DEBOUNCE=<ms>` |
| `WINDOW:<0\|50..300>` | Live-updates chord collection window (`0` = decode-on-release) and echoes `SYSTEM:WINDOW=<ms>` |
| `RESET_TIMING` | Restores `DEBOUNCE=15`, `WINDOW=0` and echoes `SYSTEM:TIMING_DEFAULT` |

```javascript Web Bluetooth (Browser)
const NUS_SERVICE = '6e400001-b5a3-f393-e0a9-e50e24dcca9e';
const NUS_TX = '6e400002-b5a3-f393-e0a9-e50e24dcca9e';
const NUS_RX = '6e400003-b5a3-f393-e0a9-e50e24dcca9e';

const device = await navigator.bluetooth.requestDevice({
  filters: [{ namePrefix: 'BrailleBridge' }],
  optionalServices: [NUS_SERVICE],
});
const server = await device.gatt.connect();
const service = await server.getPrimaryService(NUS_SERVICE);
const tx = await service.getCharacteristic(NUS_TX);
await tx.startNotifications();
tx.addEventListener('characteristicvaluechanged', (e) => {
  const line = new TextDecoder().decode(e.target.value).trim();
  console.log('BB1:', line);
});
```

```python Python (bleak BLE NUS)
import asyncio
from bleak import BleakClient

NUS_TX = "6e400002-b5a3-f393-e0a9-e50e24dcca9e"

async def listen(address: str):
    async with BleakClient(address) as client:
        await client.start_notify(
            NUS_TX, lambda _, data: print(data.decode("utf-8", errors="ignore"))
        )
        await asyncio.sleep(60)
```

```python Python (pyserial USB Backup)
import serial

with serial.Serial("COM5", baudrate=115200, timeout=1) as ser:
    while True:
        line = ser.readline().decode("utf-8", errors="ignore").strip()
        if line:
            print(line)
```
