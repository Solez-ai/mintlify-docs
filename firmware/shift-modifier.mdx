The **Shift** switch (`GPIO 32`) performs two distinct roles depending on whether you **tap** it alone or **hold** it while pressing a Braille chord.

## 1. Tap-to-Backspace (`25–1500 ms`)

Tapping and releasing `SHIFT` without pressing any dot keys or `SPACE` triggers `sendBackspace()`:

- Minimum tap duration: `SHIFT_TAP_MIN_MS = 25` ms
- Maximum tap duration: `SHIFT_TAP_MAX_MS = 1500` ms
- Cooldown between taps: `SHIFT_BKSP_COOLDOWN_MS = 100` ms
- **Action**: Sends BLE HID `KEY_BACKSPACE` (`0xB2`, held `8 ms` then `releaseAll()`) **and** emits `SYSTEM:BKSP` over USB Serial and BLE NUS.

## 2. Hold-as-Modifier (`processChord(chord, true)`)

When `SHIFT` is held during a chord, `processChord()` evaluates layers in this exact priority order:

### Numbers (`numberChords[10]`)
Standard Braille digits (`Shift + a..j` → `1..0`):

| Chord (`a..j` pattern) | Dots | Output |
|---|---|---|
| `0b000001` | `1` | `1` |
| `0b000011` | `1, 2` | `2` |
| `0b001001` | `1, 4` | `3` |
| `0b011001` | `1, 4, 5` | `4` |
| `0b010001` | `1, 5` | `5` |
| `0b001011` | `1, 2, 4` | `6` |
| `0b011011` | `1, 2, 4, 5` | `7` |
| `0b010011` | `1, 2, 5` | `8` |
| `0b001010` | `2, 4` | `9` |
| `0b011010` | `2, 4, 5` | `0` |

### Math & Punctuation (`shiftSymbols[]`)

| Dots | Bitmask | Output |
|---|---|---|
| `2, 3, 5` | `0b010110` | `+` |
| `3, 6` | `0b100100` | `-` |
| `2, 3, 6` | `0b100110` | `×` |
| `2, 3, 5, 6` | `0b110110` | `=` |
| `3, 4` | `0b001100` | `÷` |
| `2` | `0b000010` | `,` |
| `2, 3` | `0b000110` | `;` |
| `2, 5` | `0b010010` | `:` |
| `2, 5, 6` | `0b110010` | `.` |

### English Uppercase & Bangla Vowel Matras (`banglaShiftMap[]`)
- **English (`!isBangla`)**: Converts any lowercase `a–z` dictionary match to uppercase `A–Z`.
- **Bangla (`isBangla`)**: Maps base vowel chords in `banglaShiftMap[]` to dependent vowel signs (কার / matras): `া`, `ি`, `ী`, `ু`, `ূ`, `ে`, `ৈ`, `ো`, `ৌ`.
