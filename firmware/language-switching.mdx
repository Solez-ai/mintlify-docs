BrailleBridge supports seamless bilingual switching between **English** (`LANG:en`) and **Bangla** (`LANG:bn`) at any point mid-sentence.

## Method 1: Physical Hardware Chord (Dots 4 + 5 + 6)

Hold **Dots 4, 5, and 6** (`0b111000`) simultaneously for **`500 ms`** (`LANG_HOLD_MS = 500`):

```cpp
if (chordBits == 0b111000 && (now - chordStartTime >= LANG_HOLD_MS)) {
  isBangla = !isBangla;
  streamOut(isBangla ? "LANG:bn" : "LANG:en", true);
  // Wait up to 2000 ms for keys to release before resuming
}
```

## Method 2: Remote BLE NUS Command

Desktop, Android, and Web hosts can switch the device's language programmatically by writing `LANG:en` or `LANG:bn` to the **NUS RX Characteristic** (`6E400003-B5A3-F393-E0A9-E50E24DCCA9E`):

```cpp
void onNusControl(const char* cmd) {
  if (strcmp(cmd, "LANG:en") == 0) {
    isBangla = false;
    streamOut("LANG:en", true);
  } else if (strcmp(cmd, "LANG:bn") == 0) {
    isBangla = true;
    streamOut("LANG:bn", true);
  } else {
    streamOut("Invalid", true);
  }
}
```

<Info>
  When switching to Bangla, remember that multi-byte UTF-8 characters (`অ`–`ঁ`) are delivered over **BLE NUS** and **USB Serial** (`115200` baud) rather than BLE HID. Desktop, Android, and Web clients reassemble multi-byte UTF-8 sequences automatically.
</Info>
