BrailleBridge uses **Grade 1 uncontracted 6-dot Braille** for English and **Bharati Braille** for Bangla, decoded inside `braile/braile.ino`.

## 15 ms Stability Debounce

Every switch input passes through a `PinFilter` state machine (`DEBOUNCE_MS = 15`). A transition only becomes `f.stable` after the raw `digitalRead(f.pin) == LOW` state stays unchanged for at least `15 ms`:

```cpp
void updateFilters() {
  unsigned long t = millis();
  for (int i = 0; i < PIN_COUNT; i++) {
    bool r = (digitalRead(filters[i].pin) == LOW);
    if (r != filters[i].raw) {
      filters[i].raw = r;
      filters[i].lastChange = t;
    } else if ((t - filters[i].lastChange) >= DEBOUNCE_MS) {
      filters[i].stable = r;
    }
  }
}
```

## Decode-on-Release State Machine

Rather than committing after a fixed `180 ms` timer, `loop()` accumulates bits in `chordBits` as long as **any** dot key is held and evaluates the chord the moment **all** dot keys release (`!anyDot`):

```cpp
uint8_t curMask = 0;
if (pressed(P_D1)) curMask |= (1 << 0);
if (pressed(P_D2)) curMask |= (1 << 1);
if (pressed(P_D3)) curMask |= (1 << 2);
if (pressed(P_D4)) curMask |= (1 << 3);
if (pressed(P_D5)) curMask |= (1 << 4);
if (pressed(P_D6)) curMask |= (1 << 5);

bool anyDot = (curMask != 0);
if (anyDot) {
  if (chordBits == 0) chordStartTime = now;
  if (curMask != chordBits) lastChordChangeTime = now;
  chordBits |= curMask;
  if (shiftDown) shiftWasUsed = true;
}

if (chordBits != 0 && !anyDot) {
  processChord(chordBits, shiftWasUsed);
  chordBits = 0;
  shiftWasUsed = false;
}
```

<Info>
  **Stuck-Key Safety Guard:** If a chord other than `0b111000` (Dots 4+5+6 language switch) remains held without changing for `CHORD_HOLD_MAX_MS = 5000` ms, `loop()` commits it automatically and resets `chordBits`.
</Info>

## Dot 6 Capital Sign (`CAPS_OFF` / `CAPS_ONCE` / `CAPS_LOCK`)

Pressing **Dot 6 alone** (`0b100000`) without `SHIFT` cycles the `CapsMode` state machine and broadcasts the state to connected hosts:

```cpp
enum CapsMode { CAPS_OFF, CAPS_ONCE, CAPS_LOCK };
```

| Press Count | State | Emitted Control Line | Behavior |
|---|---|---|---|
| 1st Dot 6 | `CAPS_ONCE` | `SYSTEM:CAP_ONCE` | Uppercases the next English letter, then resets to `CAPS_OFF` |
| 2nd Dot 6 | `CAPS_LOCK` | `SYSTEM:CAP_LOCK` | Uppercases all subsequent English letters |
| 3rd Dot 6 (or Space after `CAPS_ONCE`) | `CAPS_OFF` | `SYSTEM:CAP_OFF` | Returns to lowercase |

## Dictionary Structure (`braileDict[]`)

`braileDict[]` stores `54` `BrailleEntry` mappings (`uint8_t chord; const char* en; const char* bn;`), covering `a–z` and Bharati Braille vowels, consonants, `্` (halant, dot 4), `ং` (anusvara, dots 5+6), `ঁ` (candrabindu, dot 5), plus convenience chords (`0b100110` → `ি`, `0b110010` → `ূ`, `0b100010` → `স`).
